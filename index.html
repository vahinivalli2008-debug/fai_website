PROJECT INFORMATION
About ClubLogic

    
Project objective
ClubLogic is a student-facing eligibility checker based on a small Prolog knowledge base. It helps students understand whether they satisfy a campus club's CGPA, attendance and interest requirements.
How it works
  1. Student selects a club and enters details.
  2. The reasoner compares each detail with the club facts.
  3. Every failed condition is collected as a reason.
  4. If the reasons list is empty, the result is eligible; otherwise, it is not eligible.

    
Note: This browser application mirrors the rules in your Prolog file using JavaScript. To execute the original Prolog program itself, run eligibility.pl in SWI-Prolog.
